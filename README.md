## 🕶️ What this is
**Saavn** was a Discord music bot built on **JDA + LavaPlayer** with slash command support, queue controls, voice channel handling, and playback utilities.

This repository is kept for reference/history and is **not actively maintained**.

---

## ⚡ Feature snapshot
- 🎵 Play tracks from links/queries
- ⏯️ Pause / Resume / Stop
- ⏭️ Skip + Queue visualization
- 🔁 Repeat control
- 🔊 Volume controls
- ➕ Voice channel join flow
- ℹ️ Ping, Help, Invite utility commands

---

## 🧩 Tech stack
- **Java + Kotlin** (mixed codebase)
- **JDA** (Discord interactions)
- **LavaPlayer** (audio playback)
- **Gradle** (build tool)

---

## 🛠️ Local run (for tinkerers)
```bash
./gradlew build
```

Bot startup entry points in this repo:
